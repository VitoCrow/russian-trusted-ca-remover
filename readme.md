Удаление российских сертификатов НУЦ Минцифры из Windows 10/11

1. Распакуйте ZIP целиком в отдельную папку.
2. Дважды нажмите START_CLEANUP.cmd.
3. Разрешите запуск от имени администратора (запрос UAC Windows).
4. В консоли отобразятся найденные сертификаты Russian Trusted Root CA / Russian Trusted Sub CA.
5. Введите DELETE (заглавными латинскими буквами) и нажмите Enter.
6. Будут созданы резервные копии .cer, затем сертификаты удалятся.
7. Отчет и копии сохраняются в папку Russian_CA_Cleanup_дата_время в вашем профиле Windows.
8. Перезапустите браузеры и, при необходимости, Windows.

Скрипт просматривает CurrentUser и LocalMachine и основные хранилища Windows.
Удаляет только сертификаты, в имени ВЛАДЕЛЬЦА которых указан Russian Trusted Root CA / Russian Trusted Sub CA.
Не удаляет сертификаты обычных сайтов Сбера, которым НУЦ является издателем.
Не трогает хранилище Disallowed (заблокированные сертификаты).
Не трогает закрытые ключи, реестр напрямую и другие учетные записи Windows.
Firefox может хранить отдельно импортированные сертификаты — удалите их через настройки Firefox.

Если найдено 0: это означает только отсутствие совпадений в проверенных хранилищах текущего пользователя и компьютера.
